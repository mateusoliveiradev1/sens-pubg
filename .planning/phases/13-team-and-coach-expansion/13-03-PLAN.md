<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| private player source -> Team snapshot | Private analysis/history/program/Lab data crosses into coach-readable models. |
| packet URL -> public-safe read | Opaque token can read a redacted Team Review Packet without login. |
| revocation -> source access | Revocation must stop future private source access while preserving audit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-13-03-01 | Information Disclosure | Team redaction | mitigate | Allowlist team-safe fields and test forbidden private fields. |
| T-13-03-02 | Elevation of Privilege | report actions | mitigate | Reload Team membership, role, entitlement, consent, and owned source rows before writes. |
| T-13-03-03 | Information Disclosure | packet links | mitigate | Use verifier hash/prefix, revocation, expiration, and disabled states. |
| T-13-03-04 | Repudiation | share/revoke/packet lifecycle | mitigate | Persist audit events for every consent and packet control change. |
</threat_model>
