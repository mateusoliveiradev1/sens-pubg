Create `src/core/training-protocols.ts`.

- `buildCompleteTrainingProtocol(input: { analysisResult?: AnalysisResult; coachPlanBase: Omit<CoachPlan, 'completeProtocol'>; memorySnapshot?: CoachMemorySnapshot }): CompleteTrainingProtocol`.
- `resolveTrainingProtocolDowngradeReasons(input)`.
- `doseForTrainingProtocolTier(tier, drillId, context)`.
- `buildTrainingProtocolPreparation(focusArea, tier, downgradeReasons)`.
- `buildTrainingProtocolValidationPlan(input)`.
- `buildTrainingProtocolTransferPlan(input)`.

Rules:
- `capture_again` duration is 5, `test_protocol` duration is 12, `stabilize_block` duration is 18, `apply_protocol` duration is 20 to 25.
- One executable protocol follows `coachPlanBase.primaryFocus`; secondary focuses become `antiMixingNotes`.
- `analysisDecision.level` below `usable_analysis` forces recapture or short test downgrade.
- `usable_analysis` cannot output an apply-strength validation copy.
- `apply_protocol` requires `analysisDecision.level === 'strong_analysis'`, no memory conflicts, no fatigue/pain, and compatible validation evidence.
- Missing distance/optic/attachment only blocks dependent fields and adds repair CTAs.
- Preparation items must be setup/control copy: pull space, relaxed grip/forearm, repeatable posture, fixed variables, pauses, and pain/numbness/tingling stop rule.

Update `buildCoachPlan` to create the base plan, call `buildCompleteTrainingProtocol`, and return `{ ...basePlan, completeProtocol }`. Avoid recursion by passing `coachPlanBase` without `completeProtocol`.
